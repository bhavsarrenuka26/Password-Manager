# 🔐 PassOP – Your own Password Manager

A simple password manager built with React. Supports storing, viewing, editing, and deleting credentials.

---

## 🚀 Versions

### 1️⃣ LocalStorage Version

* Frontend-only (no backend)
* Stores data in browser using `localStorage`

**Run:**

```bash
npm install
npm run dev
```

---

### 2️⃣ MongoDB Version (Full Stack)

* React frontend + Node.js backend
* MongoDB for persistent storage

---

## ⚙️ Backend Setup

```bash
npm install express mongodb cors body-parser dotenv
node server.js
```

Runs on: `http://localhost:3000`

---

## 🔌 API

* `GET /` → Fetch passwords
* `POST /` → Add password
* `DELETE /` → Delete password

---
